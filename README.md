# 🚀 CareerForge AI

### Don't just choose a career. Reverse-engineer it.

CareerForge AI is an AI-powered career roadmap platform that transforms a student's career goal into a personalized, actionable and adaptive learning roadmap.

Instead of giving students a generic list of skills, CareerForge AI works backwards from the target job and considers the student's current level, existing skills, available study time and target timeline.

---

## 🎯 Problem

Students often know what career they want but don't know exactly what they should learn, in what order, which projects they should build, or how long it should take.

Most existing career guidance is generic and static. Students may already know some skills, yet still receive the same roadmap.

CareerForge AI solves this by creating a personalized roadmap based on the student's individual situation.

---

## 💡 Solution

CareerForge AI asks the student for:

- Target career
- Current skill level
- Existing skills
- Available hours per week
- Target timeline

The AI then generates a career-specific roadmap containing:

- Skill requirements
- Learning milestones
- Practical projects
- Actions to perform
- Proof-of-skill activities
- Estimated timeline
- Priority levels

The roadmap can also adapt as the student learns or marks skills as already known.

---

## ✨ Key Features

### 🤖 AI-Powered Roadmap Generation
Generates a personalized roadmap dynamically using Google's Gemini AI.

### 🎯 Reverse-Engineered Career Planning
Starts with the student's target job and works backwards to identify the skills and milestones required.

### 📅 Custom Target Timeline
Students can select predefined timelines or create a custom target such as:

- 45 Days
- 8 Weeks
- 3 Months
- 6 Months
- 1 Year

### 🌳 Interactive Roadmap
The roadmap is presented as an interactive skill graph where students can explore individual milestones.

### 📚 Skill Learning Path
Every important skill provides a four-step learning path:

**Learn → Practice → Build → Prove**

### ✅ Adaptive Progress
Students can:

- Mark a skill as already known
- Mark a skill as completed
- Complete milestones
- Track overall roadmap progress

### 💼 Job-Ready Focus
The roadmap includes practical projects, portfolio development, proof of skills and interview preparation.

### 📱 Responsive Interface
Designed to work across desktop and mobile devices.
